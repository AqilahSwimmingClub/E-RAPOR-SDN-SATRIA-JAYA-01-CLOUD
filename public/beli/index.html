Cara Mendapatkan Lisensi

Enam langkah sederhana, dari mengisi data sekolah sampai e-Rapor siap dipakai.

  1. 01Isi Data SekolahLengkapi formulir pemesanan di halaman ini.
  2. 02Kirim PemesananPesan WhatsApp terbuka lebih dulu agar dapat Anda periksa.
  3. 03Developer MemverifikasiData sekolah dicek dan Anda dihubungi kembali.
  4. 04License Key DiberikanKunci resmi dibuat khusus untuk sekolah Anda.
  5. 05Aktivasi e-RaporSatu License Key untuk satu perangkat aktif.
  6. 06Siap DigunakanData akademik tersimpan lokal di perangkat sekolah.
